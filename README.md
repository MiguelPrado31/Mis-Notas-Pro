## 🚀 Características
- Manejo de rutas y controladores.
- Operaciones CRUD (crear, leer, actualizar y eliminar notas).
- Implementación de HTTPS requests (GET, POST, PUT, DELETE).
- Interfaz de Usuario (UI) moderna e intuitiva.
- Arquitectura cliente-servidor.

---

## 🛠️ Tech Stack (Tecnologías utilizadas)

### Frontend
- ReactJS
- TailwindCSS
- DaisyUI: Mensajes de error o exito


### Backend
- Express.js
- MongoDB: Implementación de la base de datos
